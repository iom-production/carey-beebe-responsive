Dreamweaver sample files

The two responsive Technical Library pages, with editable HTML, shared CSS and JavaScript, original JPEG images and short test instructions.

Download the Dreamweaver ZIP

  1. Extract the complete ZIP.
  2. In Dreamweaver, choose Site → New Site and select the extracted carey-beebe-responsive folder.
  3. Open tech/kb/prob.html or tech/kb/trans.html, make an edit and preview in your browser.
